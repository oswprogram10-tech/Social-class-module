# 접근성

이 앱은 키보드만 쓰는 학생, 화면 읽기 프로그램(크롬북의 ChromeVox 등)을 쓰는 학생, 색을 구별하기 어려운 학생도 활동에 참여할 수 있도록 만듭니다. 기준은 웹 콘텐츠 접근성 지침 WCAG 2.1 AA입니다.

## 점검한 방법

- **자동 점검:** axe-core로 첫 화면, 사용 안내, 학급 만들기, 학생 입장, 교사 화면과 학생 화면의 35가지 활동 전체, 성장 리포트, 발표 화면을 검사했습니다. 결과는 위반 0건입니다.
- **키보드만으로 해 보기:** 마우스 없이 Tab, Enter, 방향키만으로 아래를 끝까지 해 보았습니다.
  - 학생 입장(번호 → 약속 → 들어가기)
  - 지도에 장소 남기기(방향키로 지도 옮기기 → “지도 가운데에 장소 놓기” → 글쓰기)
  - 분류하기(틀리면 힌트, 맞으면 “맞아요!”를 화면 읽기 프로그램이 읽어 줌)
  - 지구본·세계 인구 지도에서 나라 고르기(“목록에서 나라 고르기”)
  - 우리나라 지도에서 도시 고르기(이름표 단추)

- **화면 읽기 프로그램이 읽는 내용 검토:** 학생 입장, 장소감 지도, 분류하기, 한국사 연표, 선거, 무역, 지구촌 문제, 세계 인구, 우리나라 기후 화면에서 화면 읽기 프로그램에 전달되는 정보(접근성 트리)를 뽑아 들리는 차례대로 읽어 보고 고쳤습니다.
  - 글 쓰는 칸이 질문 대신 예시 글(“예: 놀이터, 문구점…”)로 읽히던 13곳 → 질문(“장소 이름”, “학급 코드”)으로 읽힘
  - 지도 확대·축소 단추 “Zoom in/out” → “지도 크게 보기/작게 보기”
  - 슬라이더 “0”, “4” → “1월”, “2020년”, “밀 4시간, 휴대폰 8시간”
  - 퀴즈 “←/→” 단추 → “이전 질문/다음 질문”
  - 분류하기 단추 묶음 → “‘(카드 글)’ 어디에 들어갈까요?”
  - 학생·교사 화면에 본문 영역(main) 표시
  - “도시을(를)”처럼 어색한 조사 → “도시를”, “지형을”

## 앱에 들어 있는 것

| 어려움 | 앱에서 돕는 방법 |
|---|---|
| 마우스를 쓰기 어려워요 | 모든 단추를 Tab으로 갈 수 있어요. 지도는 방향키로 옮기고 “지도 가운데에 놓기”로 표시해요. 지구본은 방향키로 돌려요. 나라는 목록에서도 고를 수 있어요. |
| 화면이 보이지 않아요 | 화면마다 탭 제목이 바뀌어요. 그림 단추와 지도에는 이름이 붙어 있고, 정답 확인 결과와 힌트를 바로 읽어 줘요. |
| 글 읽기가 어려워요 | 활동 안내, 질문, 카드 글에 🔊 읽어 주기 단추가 있어요. |
| 색을 구별하기 어려워요 | 글자와 바탕의 명암 대비를 4.5:1 이상으로 맞췄어요. 지도의 색은 고르면 숫자와 글로도 보여 줘요. |
| 움직임에 어지러워요 | 기기에서 “움직임 줄이기”를 켜면 애니메이션이 꺼져요. |
| 지금 어디에 있는지 놓쳐요 | Tab으로 간 곳에 진한 주황 테두리가 보여요. 지도에서 도시를 고른 뒤에도 그 자리에 그대로 있어요. |

## 아직 남은 것

- 실제 크롬북 ChromeVox로 수업 전체를 소리로 들어 보는 점검은 아직 하지 않았습니다(위 검토는 화면 읽기 프로그램에 전달되는 정보를 확인한 것입니다).
- 제목과 단추의 그림 문자(🗺️, 📖 등)는 화면 읽기 프로그램이 그림 이름으로 함께 읽을 수 있습니다. 해 보신 선생님은 [의견 보내기](../README.md#고칠-점과-제안-보내기)로 알려 주세요.
- 위키미디어 공용 사진은 사진 설명(대체 글)이 카드 글과 같습니다. 사진만의 자세한 설명은 아직 없습니다.
- 학급 지도(오픈스트리트맵·브이월드) 배경 그림 안의 글자는 지도 회사가 그린 것이라 대비를 바꿀 수 없습니다.

## 개발할 때

- 새 단추는 `<button>`으로 만들고, 그림만 있는 단추에는 `aria-label`을 붙입니다.
- 정답 확인이나 힌트처럼 눌렀을 때 바뀌는 글은 `role="status"` 안에 넣습니다.
- 글 쓰는 칸은 `<label htmlFor>`와 `id`로 질문과 잇습니다. 🔊 읽어 주기 단추를 `<label>` 안에 넣으면 질문이 단추에 붙어 버립니다.
- 슬라이더에는 `aria-valuetext`로 “1월”처럼 뜻이 있는 값을 붙입니다.
- 조사는 `src/content/josa.ts`의 `eulReul`, `iGa`를 씁니다.
- 색은 `src/styles.css` 맨 위의 색 변수를 씁니다(대비를 맞춰 둔 색입니다).
- 지도나 그림에서만 고를 수 있는 것은 목록이나 단추로도 고를 수 있게 합니다.
