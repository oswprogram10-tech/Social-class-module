# 개발 로드맵

## 조건

- 개인 교사 개발, 예산 0원, 기간 제한 없음
- 웹 링크(PWA)로 배포: 크롬북 기준, 다른 플랫폼에서는 링크로 공유
- 원본 구상: Gemini Deep Research가 작성한 「2022 개정 초등 사회과 교육과정 분석 및 에듀테크 앱 개발 명세서」의 5대 모듈 중, 비용 0원으로 만들 수 있는 부분부터 단계적으로 구현합니다.

## 원칙

1. **공통 활동 엔진 + 단원별 설정:** 단원마다 새 앱을 만들지 않고, 활동 유형(지도 핀, 레이어, 연표, 사료, 선택 시뮬레이션, 팩트체크)을 엔진으로 만든 뒤 `activities.ts` 같은 설정으로 단원을 찍어냅니다.
2. **서버 없음:** 정적 웹앱 + Firebase 무료 요금제만 씁니다.
3. **개인정보 최소화:** 실명, 사진, 음성을 받지 않습니다.
4. **AI는 마지막에:** 처음에는 교사가 쓴 '생각 도우미 질문'으로 소크라테스식 발문을 대신합니다. LLM은 비용과 미성년자 이용 약관을 검토한 뒤 도입합니다.
5. **내 수업 진도에 맞춰** 한 단원씩 만들고, 실제 수업에서 써 본 뒤 고칩니다.

## 단계

### ✅ 1단계: 우리 동네 장소감 지도

- [4사01-01] 장소감 지도, [4사01-02] 더 살기 좋은 우리 동네
- 교사: 학급 생성, 활동 전환, 승인·숨김, 발표 화면, CSV 내보내기
- 학생: 코드로 입장, 핀 남기기·고치기, 공감, 읽어주기(TTS)

### ✅ 2단계: 지도 엔진 확장 (3~4학년)

- [x] [4사05-01·02] 방위와 거리 미션: 방위표, 축척 막대, 자동 확인과 힌트(정답을 알려 주지 않음), 학생 × 미션 진행표
- [x] [4사09-01] 지역문제 해결 4단계(문제 → 원인 → 두 방법 비교 → 결론): 단계별 저장, 교사가 진행 상황을 실시간으로 확인
- [x] 교사가 생각 도우미 질문을 학급별로 고치는 기능
- [x] 교사 Google 계정 연결로 다른 기기에서 학급 관리

### ✅ 3단계: 새 활동 엔진

- [x] [4사09-02] 우리 지역 알리기: 자랑거리 핀, 한 줄 홍보 문구 카드, 공감
- [x] [4사05-01] 우리 반 지도 기호 만들기: 학생이 정한 기호로 범례 자동 생성, 기호가 다르면 ⚠️ 표시
- [x] **연표** 엔진: [4사02-01] 나의 연표 (지도 없는 화면, 본인과 교사만 열람)
- [x] **팩트체크 스튜디오:** [6사08-03] 문장별 사실/의견 표시와 자동 확인(정답 대신 힌트), 출처 체크리스트, 믿을 만한 정도 판단, 교사가 자료 직접 만들기
- [x] **선택 시뮬레이션:** [4사07-01] 기회비용 장터, [6사08-01] 선거 4원칙 지키기(원칙이 깨진 이야기 6개)
- [x] 연표·미션·퀴즈형 기록은 보안 규칙에서도 본인과 교사만 읽도록 강화
- [ ] 연표 엔진을 5학년 2학기 한국사(시대 순서 배열)로 확장

### 4단계: 5~6학년 지도 레이어

- [ ] 공공데이터(통계청 SGIS, KOSIS) 기반 인구·기후 레이어와 타임 슬라이더: [6사02-01~02]
- [ ] 지구본과 세계지도 비교: [6사09-01~02]

### 5단계: 검토 후 선택

- [ ] AI 질문 튜터(정답 대신 질문). 비용과 약관 검토 필요
- [ ] 3범주(지식·이해 / 과정·기능 / 가치·태도) 성장 리포트
- [ ] 다른 교사가 쉽게 복제할 수 있는 설치 안내 영상

## 범위에서 제외

360° VR 시대 전환, 3D 유물 단면, 메타버스 전시관, 학부모 앱, AIDT 포털 연동, CSAP 인증. 모두 콘텐츠 제작비나 인증 비용이 커서 예산 0원 조건에 맞지 않습니다.
