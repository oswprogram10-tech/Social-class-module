# 로드맵

이 앱은 초등 사회 3~6학년 선생님들이 무료로 가져다 쓰는 수업 도구입니다. 이 문서는 앱이 지키는 원칙, 지금 들어 있는 것, 앞으로 할 일을 정리합니다.

## 원칙

1. **누구나 무료로:** 정적 웹앱과 Firebase 무료 요금제만 씁니다. 서버를 따로 운영하지 않아, 학교마다 자기 저장소를 복사(Fork)해 직접 관리할 수 있습니다.
2. **개인정보 최소화:** 학생의 실명, 이메일, 사진, 음성을 받지 않습니다. 친구에게 보이는 기록과 학생·교사만 보는 기록을 보안 규칙으로 나눕니다.
3. **교육과정에 맞춘 활동:** 2022 개정 사회과 교육과정의 단원과 성취기준에 맞춰 활동을 만듭니다.
4. **공통 활동 엔진 + 단원별 내용:** 단원마다 새 앱을 만들지 않고, 활동 방식(학교 지도, 탐구 질문, 분류하기, 차례 놓기, 단계별 탐구, 시뮬레이션)을 엔진으로 만든 뒤 내용만 바꿔 씁니다.
5. **정답 대신 힌트:** 앱이 확인하는 문제는 틀리면 생각을 돕는 질문을 보여 줍니다.
6. **믿을 수 있는 자료:** 통계는 공식 출처만 쓰고 출처를 화면에 밝힙니다. 수업을 위해 지어낸 자료는 가상이라고 밝힙니다. 사진은 자유 라이선스만 쓰고 작가와 라이선스를 표시합니다.
7. **AI는 교사의 도구로:** 학생은 AI를 쓰지 않습니다. 선생님 PC의 로컬 AI가 만든 결과는 초안이며, 선생님이 확인한 뒤에만 학생에게 보입니다.

## 지금 들어 있는 것

- 3~6학년 모든 단원에 35가지 활동이 있습니다. 목록은 [활동 안내서](activities.md)를 보세요.
- 교사 화면: 실시간 결과표, 발표 화면, 승인·숨김, 생각 도우미 질문 고치기, 엑셀 저장, 3범주 성장 리포트
- 선택 기능: Google 계정으로 다른 기기에서 학급 관리, 브이월드 지도, 교사 전용 로컬 AI 도우미

## 앞으로 할 일

- [x] **학부모 안내문 견본:** 학교에서 쓰기 전에 보낼 안내문과 확인 목록 ([parent-notice.md](parent-notice.md), 앱의 사용 안내에서 복사)
- (따로 진행) **설치 쉽게 하기:** 별도 플랫폼에 올려 배포할 예정이라 이 저장소에서는 다루지 않습니다.
- [x] **선생님 의견 받기:** 고칠 점·내용 바로잡기·새 활동 제안 양식(GitHub Issues), 사용 안내와 교사 화면에서 바로 열기
- [x] **접근성 점검:** 자동 점검(WCAG 2.1 AA) 위반 0건, 키보드만으로 활동하기, 색 대비, 읽어 주기 ([accessibility.md](accessibility.md))
- [ ] **화면 읽기 프로그램 실제 점검:** ChromeVox로 수업 전체를 들어 보고 고치기
- [ ] **오프라인 대비:** 학교 인터넷이 느릴 때를 위해 앱 파일을 미리 저장해 두기(PWA 캐시)
- [ ] (보류) **학생용 AI 튜터:** 비용, 이용 약관(미성년자), 학교 승인 문제로 지금은 하지 않습니다.
