# 개발 로드맵

## 조건

- 개인 교사 개발, 예산 0원, 기간 제한 없음
- 웹 링크(PWA)로 배포: 크롬북 기준, 다른 플랫폼에서는 링크로 공유
- 원본 구상: Gemini Deep Research가 작성한 「2022 개정 초등 사회과 교육과정 분석 및 에듀테크 앱 개발 명세서」의 5대 모듈 중, 비용 0원으로 만들 수 있는 부분부터 단계적으로 구현합니다.

## 원칙

1. **공통 활동 엔진 + 단원별 설정:** 단원마다 새 앱을 만들지 않고, 활동 유형(지도 핀, 레이어, 연표, 사료, 선택 시뮬레이션, 팩트체크)을 엔진으로 만든 뒤 `activities.ts` 같은 설정으로 단원을 찍어냅니다.
2. **서버 없음:** 정적 웹앱 + Firebase 무료 요금제만 씁니다.
3. **개인정보 최소화:** 실명, 사진, 음성을 받지 않습니다.
4. **AI는 마지막에:** 처음에는 교사가 쓴 '생각 도우미 질문'으로 소크라테스식 발문을 대신합니다. LLM은 비용과 미성년자 이용 약관을 검토한 뒤 도입합니다.
5. **내 수업 진도에 맞춰** 한 단원씩 만들고, 실제 수업에서 써 본 뒤 고칩니다.

### ✅ 1단계: 우리 동네 장소감 지도

- [4사01-01] 장소감 지도, [4사01-02] 더 살기 좋은 우리 동네

- 학생: 코드로 입장, 핀 남기기·고치기, 공감, 읽어주기(TTS)

### ✅ 2단계: 지도 엔진 확장 (3~4학년)

- [x] [4사09-01] 지역문제 해결 4단계(문제 → 원인 → 두 방법 비교 → 결론): 단계별 저장, 교사가 진행 상황을 실시간으로 확인
- [x] 교사가 생각 도우미 질문을 학급별로 고치는 기능
