# 학부모 안내문 견본

학교에서 이 앱을 쓰기 전에 학부모님께 보낼 안내문 견본입니다. 앱의 📖 사용 안내 → “4. 안전과 개인정보”에서도 복사할 수 있습니다.

> 이 견본은 법률 자문이 아닙니다. 학교의 절차와 양식이 우선입니다.

## 보내기 전에 확인할 것

- 학교의 학습지원 소프트웨어 선정 절차와 개인정보 처리 절차를 학교 담당자(정보·개인정보 보호 담당)에게 먼저 확인해요. 학교에 따라 학교운영위원회 심의나 보호자 동의서가 필요할 수 있어요.
- [ ] 안의 빈칸을 채우고, 학교에서 필요 없다고 하면 회신란은 지워요.
- Firebase 콘솔의 Firestore 설정에서 데이터 위치를 확인해 3번에 적어요(설치 안내대로 만들었다면 서울, asia-northeast3).
- 브이월드 지도를 켰다면 6번의 지도 이름을 “브이월드(국토교통부)”로 바꿔요. 선생님이 로컬 AI 도우미를 쓴다면 “선생님 컴퓨터 안에서만 동작하며 학생 이름을 보내지 않습니다”를 덧붙일 수 있어요.
- 첫 수업 때 별명에 이름이나 전화번호를 쓰지 않도록 지도해요.
- 보관 기간이 끝나면 교사 화면의 “엑셀로 저장”으로 필요한 기록만 학교 규정대로 보관하고, “모두 지우기”로 기록을 지워요. 저장한 엑셀 파일에도 번호와 별명이 들어 있으니 학교 규정에 따라 관리해요.

## 안내문 견본

`[ ]` 안의 빈칸을 채워 학교 가정통신문 양식에 붙여 쓰세요.

```text
사회 수업 웹앱 「우리 동네 지도 탐구」 이용 안내

학부모님, 안녕하세요. [학교 이름] [학년]학년 [반]반 담임 [선생님 이름]입니다.
[시작 날짜]부터 사회 시간에 학생들이 학교 크롬북으로 웹앱 「우리 동네 지도 탐구」를 사용합니다. 학생들은 지도, 연표, 분류하기 같은 활동으로 사회 개념을 탐구하고, 자기 생각을 짧은 글로 남깁니다. 이 앱이 다루는 정보를 아래와 같이 안내드립니다.

1. 이용 목적
- 초등 사회과 수업 활동(2022 개정 교육과정 성취기준에 맞춘 지도·연표·탐구 활동)
- 선생님이 학생의 학습 과정을 확인하고 피드백하기

2. 학생이 입력하는 정보
- 학급 코드와 출석 번호
- 별명(선택, 10자 이내). 이름은 쓰지 않도록 지도합니다.
- 활동 기록: 지도에 표시한 장소와 그 까닭, 퀴즈·분류하기 답, 연표, 짧은 글
- 앱은 학생의 이름, 이메일, 전화번호, 사진, 음성, 기기 위치(GPS)를 받지 않습니다. 학생은 계정을 만들지 않고, 기기마다 자동으로 정해지는 무작위 번호(익명 로그인)로 접속합니다.

3. 저장 위치와 보관 기간
- 기록은 담임교사가 만들어 관리하는 Google Firebase 저장소(데이터 위치: [서울])에 저장됩니다. 앱을 만든 사람이나 다른 학교는 이 기록을 볼 수 없습니다.
- [학년도 말]까지 보관한 뒤 모두 지웁니다.

4. 기록을 볼 수 있는 사람
- 담임교사: 우리 반의 모든 기록
- 같은 반 친구: 지도에 남기는 일부 활동(장소에 대한 느낌, 동네 개선 의견, 지역 알리기, 문화유산 등) 가운데 선생님이 공개한 기록. 친구들 화면에는 누가 썼는지 나오지 않습니다.
- 연표, 퀴즈, 분류하기 같은 나머지 기록은 학생 본인과 담임교사만 봅니다.

5. 안전을 위한 약속
- 학생은 앱에 들어갈 때 "우리 집이나 친구 집 위치는 지도에 표시하지 않아요. 친구의 느낌을 존중해요."라는 약속에 동의합니다.
- 부적절한 글은 선생님이 숨기거나 지웁니다.

6. 외부 사이트 연결
- 지도 그림([오픈스트리트맵])과 일부 사진(위키미디어 공용)을 학생 기기가 직접 불러옵니다. 이때 학생 정보는 보내지 않지만, 일반 누리집을 열 때처럼 그 사이트에 접속 기록(인터넷 주소 등)이 남을 수 있습니다.
- 학생은 AI 기능을 쓰지 않습니다.

7. 문의
- 궁금하신 점은 [연락 방법]으로 연락해 주세요.

[필요한 경우에만 아래 회신란을 사용하세요]
-------------------------------------------------------------
「우리 동네 지도 탐구」 사용에 대하여
( ) 사용에 동의합니다.   ( ) 사용을 원하지 않습니다.
※ 사용을 원하지 않으면 같은 내용을 종이 활동지로 공부합니다.

[학년]학년 [반]반 [번호]번   학생 이름:            보호자:            (서명)
```

## 안내문 내용의 근거

| 안내문 내용 | 앱에서 확인할 곳 |
|---|---|
| 학생이 입력하는 정보(번호, 별명, 활동 기록) | 학생 입장 화면, `src/data/types.ts` |
| 이름·이메일·사진·음성·위치를 받지 않음, 익명 로그인 | 학생 입장 화면, Firebase 익명 로그인 |
| 친구에게 보이는 기록과 학생·교사만 보는 기록 | `firestore.rules`의 `sharedActivities()` |
| 친구 화면에 작성자가 나오지 않음 | 학생 화면의 친구 기록 카드 |
| 선생님이 숨기기·지우기·모두 지우기 | 교사 화면 |
| 지도 그림과 사진의 외부 연결 | 오픈스트리트맵(또는 브이월드) 지도, 위키미디어 공용 사진 |

이 문서는 `src/content/parentNotice.ts`에서 만든 것입니다. 견본을 고칠 때는 그 파일을 고친 뒤 이 문서도 같이 바꿔 주세요.
