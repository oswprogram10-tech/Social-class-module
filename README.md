# 🗺️ 우리 동네 지도 탐구

초등 사회 3~6학년 선생님을 위한 무료 수업 도구입니다. 2022 개정 사회과 교육과정의 **3~6학년 모든 단원**에 맞춘 49가지 활동이 들어 있습니다. 학생들이 크롬북으로 활동하면 선생님 화면에 실시간으로 모입니다.

- **설치 없이 웹 주소로** 엽니다. 크롬북 기준으로 만들었고 태블릿에서도 동작합니다.
- **비용이 들지 않습니다.** GitHub Pages와 Firebase 무료 요금제, 브라우저 내장 음성을 씁니다.
- **학생 개인정보를 받지 않습니다.** 학급 코드와 번호, 고를 수 있는 별명만 씁니다.
- **정답 대신 힌트:** 틀리면 정답을 알려 주지 않고 생각을 돕는 질문을 보여 줍니다.
- **3범주 성장 리포트:** 지식·이해, 과정·기능, 가치·태도 근거를 학생별로 모아 줍니다(가치·태도는 점수 없이 학생의 글만).
- **접근성:** 마우스 없이 키보드만으로 활동할 수 있게 점검했고, 화면 읽기 프로그램이 정답 확인과 힌트를 읽도록 만들었습니다([접근성](docs/accessibility.md)).
- 통계 자료는 공식 출처만 쓰고(그래프 아래에 기관과 자료 이름을 밝힘), 지어낸 자료(선거 이야기, 팩트체크 기사, 무역 나라 등)는 화면에 가상이라고 밝혔습니다.

## 시작하는 두 가지 방법

| | ① 바로 체험하기 | ② 우리 학교에서 수업에 쓰기 (학급 모드) |
|---|---|---|
| 준비 | 없음. 주소만 열면 됩니다 | 저장소 복사와 Firebase 설정 (처음 한 번, 약 20분) |
| 기록 저장 | 그 브라우저에만 | 우리 학교 Firebase에 |
| 학생 크롬북 연결 | 안 됨 (한 크롬북의 여러 탭끼리만) | 여러 크롬북이 실시간으로 연결 |
| 이럴 때 | 활동을 미리 살펴볼 때 | 실제 수업 |

> 공개 주소 `https://oswprogram10-tech.github.io/Social-class-module/`는 **체험 모드**로만 동작합니다. 여러 학생의 크롬북을 연결하려면 아래 ②처럼 우리 학교용 주소를 따로 만들어야 합니다. 기록이 다른 학교와 섞이지 않고, 우리 학교가 직접 관리할 수 있습니다.

## ① 바로 체험하기

1. 위의 공개 주소를 엽니다.
2. 크롬에서 탭을 두 개 열고, 한쪽은 **선생님: 학급 만들기**, 다른 쪽은 **학생으로 참여하기**로 들어갑니다.
3. 선생님 탭에서 활동을 바꾸면 학생 탭도 바로 바뀝니다.

- 기록은 그 브라우저에만 저장됩니다.
- 한 브라우저의 탭들은 같은 사람으로 취급됩니다. 학생 탭을 여러 개 열어도 번호가 다르면 기록은 따로 열리지만, 실제 학생 구분은 학급 모드에서 정확히 동작합니다.

## ② 우리 학교에서 수업에 쓰기 (학급 모드)

필요한 것: GitHub 계정과 Google 계정(둘 다 무료). 코드를 고칠 줄 몰라도 됩니다. 모든 설정은 웹 화면에서 합니다.

### 1단계. 우리 학교용 주소 만들기 (GitHub Pages)

1. GitHub에 로그인하고 이 저장소 오른쪽 위의 **Fork**를 눌러 내 계정으로 복사합니다.
2. 복사한 저장소에서 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭을 엽니다. “Workflows aren't being run on this forked repository” 안내가 보이면 **I understand my workflows, go ahead and enable them**을 누릅니다.
4. 왼쪽의 “Deploy to GitHub Pages”를 고르고 **Run workflow**를 누릅니다. 1~2분 뒤 `https://내아이디.github.io/Social-class-module/` 주소가 생깁니다.

이 주소는 아직 체험 모드입니다. 다음 단계에서 학급 모드를 켭니다.

### 2단계. 학급 모드 켜기 (Firebase, 무료)

1. <https://console.firebase.google.com> 에 Google 계정으로 들어가 **프로젝트 추가**를 누릅니다.
   - 이름 예: `우리학교-사회` / Google 애널리틱스는 **사용 안 함**
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **익명**을 사용 설정합니다.
3. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
   - 위치: `asia-northeast3 (서울)` / **프로덕션 모드**로 시작
4. Firestore의 **규칙** 탭에서 기존 내용을 모두 지우고, 내 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여 넣은 뒤 **게시**합니다.
5. **프로젝트 설정(⚙️) → 일반 → 내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록합니다(호스팅 체크는 하지 않음).
6. 화면에 나오는 `firebaseConfig` 값을 내 저장소의 [`src/config.ts`](src/config.ts)에 옮겨 적습니다.
   - GitHub 웹에서 파일을 열고 연필(✏️) 아이콘으로 고친 뒤 **Commit changes**를 누르면 됩니다. 1~2분 뒤 자동으로 다시 배포됩니다.

내 주소의 첫 화면에서 노란 “체험 모드” 안내가 사라지면 학급 모드로 바뀐 것입니다.

> `firebaseConfig` 값은 공개되어도 괜찮은 값입니다. 학생 기록은 `firestore.rules` 보안 규칙이 지킵니다.

**비용:** Spark(무료) 요금제는 결제 수단을 등록하지 않아 요금이 청구되지 않습니다. 하루 한도(읽기 5만 건 등)를 넘으면 그날만 멈추며, 한 학교 몇 학급이 수업에서 쓰는 양은 한도보다 훨씬 적습니다. **결제 수단을 등록(Blaze 요금제로 전환)하지 마세요.**

### (선택) 다른 기기에서도 학급 관리하기

학급은 처음 만든 브라우저에서 관리합니다. 교사가 Google 계정을 연결해 두면 다른 기기에서도 관리할 수 있습니다. 학생은 Google 계정을 쓰지 않습니다.

1. Firebase **Authentication → 로그인 방법**에서 **Google**을 사용 설정합니다.
2. **Authentication → 설정 → 승인된 도메인**에 내 주소의 앞부분(예: `내아이디.github.io`)을 추가합니다.
3. 학급을 만든 브라우저의 교사 화면 아래쪽에서 **Google 계정 연결**을 누릅니다.
4. 다른 기기에서는 첫 화면의 **🔑 다른 기기에서 내 학급 관리하기**로 같은 Google 계정에 로그인합니다.

### (선택) 브이월드 지도 쓰기

기본 지도는 OpenStreetMap입니다. 국토교통부 **브이월드** 키를 넣으면 국내 배경지도와 영상지도(항공사진)를 쓸 수 있습니다.

1. <https://www.vworld.kr> 에 가입하고 **오픈API → 인증키 발급**을 진행합니다. 서비스 URL에는 내 주소의 앞부분(예: `https://내아이디.github.io`)을 넣습니다.
2. 발급된 키를 [`src/config.ts`](src/config.ts)의 `vworldKey`에 넣고 커밋합니다.

### (선택) 로컬 AI 도우미 — 선생님 PC 전용, 무료

선생님 PC에서 AI 모델을 직접 돌려, 교사 화면에서 다음 **초안**을 만듭니다.

- 🤖 **생각 도우미 질문:** 활동마다 정답 대신 생각을 이끄는 질문 4개
- 🤖 **팩트체크 자료:** 주제를 적으면 지어낸 기사와 문장별 사실/의견 정답
- 🤖 **성장 리포트 소견:** 학생 기록 요약을 바탕으로 쓴 2~3문장 소견

지켜지는 것:
- **학생은 AI를 쓰지 않습니다.** 학생 화면에는 AI 기능이 없습니다.
- 요청은 선생님 PC(localhost)로만 가고, 인터넷의 AI 서비스로 나가지 않습니다. 비용이 들지 않습니다.
- 소견을 만들 때 **학생 이름·번호·별명은 보내지 않습니다.**
- AI 결과는 항상 편집 칸에 “초안”으로 들어갑니다. 선생님이 확인하고 고쳐서 저장해야만 학생에게 보입니다. 작은 모델은 숫자나 역사적 사실을 틀릴 수 있으니 꼭 확인해 주세요.

#### 설치 (윈도우, 처음 한 번)

1. <https://ollama.com> 에서 Windows용 Ollama를 내려받아 설치합니다. 설치가 끝나면 작업 표시줄 오른쪽 아래에 라마 아이콘이 생깁니다.
2. **모델 받기:** 시작 메뉴에서 “명령 프롬프트”를 열고 아래처럼 입력합니다. 모델 파일은 약 5GB입니다.
   ```
   ollama pull qwen2.5:7b
   ```
   - 메모리 16GB PC라면 7~9B 크기 모델이 알맞습니다. 한국어를 잘하는 계열은 Qwen, Gemma, EXAONE 등입니다.
   - 정확한 최신 모델 이름은 <https://ollama.com/library> 에서 확인하세요. 모델마다 **라이선스**가 다르니 쓰기 전에 확인하세요(예: EXAONE은 비상업 라이선스).
   - 너무 느리면 더 작은 모델(예: `qwen2.5:3b`)을 받으세요. 빠르지만 한국어 품질은 떨어집니다.
3. **이 앱의 접속 허용:**
   1. 윈도우 검색창에 “환경 변수”를 입력하고 **계정의 환경 변수 편집**을 엽니다.
   2. 위쪽 “사용자 변수”에서 **새로 만들기**를 누르고 아래 값을 넣습니다.
      - 변수 이름: `OLLAMA_ORIGINS`
      - 변수 값: 이 앱을 여는 주소의 앞부분 (예: `https://내아이디.github.io`)
   3. 작업 표시줄의 라마 아이콘을 오른쪽 클릭해 **Quit Ollama**를 누른 뒤, 시작 메뉴에서 Ollama를 다시 켭니다.
4. **앱에서 연결:** 같은 PC의 크롬에서 교사 화면을 열고, 아래쪽 **🤖 로컬 AI 도우미 → 로컬 AI 도우미 쓰기**를 체크한 뒤 **연결 설정 → 연결 확인**을 누릅니다.
   - 크롬이 “로컬 네트워크의 기기에 액세스”를 물으면 **허용**을 누릅니다.
   - 연결되면 받은 모델이 목록에 나옵니다. 모델을 고르면 끝입니다.

#### 쓰는 곳
- 활동 설정의 **✏️ 생각 도우미 질문 고치기 → 🤖 AI로 질문 만들기**
- 팩트체크 스튜디오의 **➕ 자료 만들기 → 주제 입력 → 🤖 AI로 자료 초안 만들기**
- 성장 리포트 학생 카드의 **🤖 AI 소견 초안**

**속도:** 그래픽카드 없이 CPU로 돌리면 7B 모델 기준 한 번에 30초~2분 걸릴 수 있습니다. 진행 상황이 표시되고, 언제든 **취소**할 수 있습니다.

> 처음 설정할 때 연결이 잘 되는지 꼭 확인해 주세요. 잘 안 되면 연결 설정 화면의 안내 문구를 따라 하세요.


### 새 기능 받기 (업데이트)

이 저장소에 새 활동이나 고친 점이 생기면, 내 저장소 첫 화면의 **Sync fork → Update branch**를 누르면 됩니다. 자동으로 다시 배포됩니다.

- 업데이트 내용에 **보안 규칙(`firestore.rules`) 변경**이 있으면, 2단계의 4번처럼 Firebase 규칙 탭에 새 내용을 붙여 넣고 **게시**해야 합니다. 그러지 않으면 새 활동의 기록이 저장되지 않습니다.
- `src/config.ts`에 넣은 내 설정값은 업데이트해도 그대로 남습니다. 충돌 안내가 나오면 내 설정값을 남겨 주세요.

## 수업에서 쓰기

### 수업 전 (교사)

1. 첫 화면에서 **선생님: 학급 만들기**를 누르고, 학교를 검색하거나 지도에서 눌러 위치와 탐색 범위(500m~3km)를 정합니다.
2. 교사 화면 위쪽의 **학급 코드**를 TV에 띄우거나, **입장 주소 복사**로 링크를 클래스룸에 올립니다.
3. 사진이 있는 활동(세계의 지형 경관, 한국사 유물)은 학교 인터넷에서 사진이 보이는지 한 번 열어 확인해 주세요. 막혀 있으면 그림 기호가 대신 나오고 활동은 그대로 할 수 있습니다.

### 수업 중

1. 학생은 **학생으로 참여하기** → 학급 코드, 번호(·별명) → “우리의 약속”(집 위치 표시 금지, 친구 존중)에 동의하고 들어옵니다.
2. 교사 화면의 **활동 탭**을 누르면 모든 학생 화면이 그 활동으로 바뀝니다.
3. 학생 기록이 교사 화면에 실시간으로 모입니다. 누가 어디서 막혔는지 보고 바로 도울 수 있습니다.
4. **🖥️ 발표 화면**으로 바꾸면 TV에 반 전체 요약과 토의 질문을 크게 보여 줍니다. 학생 이름은 “번호 보이기”를 켤 때만 보입니다.

### 수업 뒤

- **📊 성장 리포트:** 학생별 3범주 기록, 선생님 메모, 인쇄, 엑셀 저장.
- **📥 엑셀로 저장:** 모든 활동의 기록을 CSV로 내려받아 과정 중심 평가 자료로 씁니다.
- **🧹 모두 지우기:** 학기 말에 학급 기록을 정리합니다(먼저 엑셀로 저장).

### 관리 기능

- **✏️ 생각 도우미 질문 고치기:** 활동마다 학생에게 보여 줄 질문을 우리 반에 맞게 바꿉니다(최대 5개).
- **선생님이 승인한 장소만 친구에게 공개:** 첫 수업이나 저학년에서 켜 두면 부적절한 글이 친구에게 보이지 않습니다.
- **학생들이 친구 장소 보기:** 끄면 각자 자기 기록만 봅니다.
- 지도 기록마다 승인, 숨기기, 지우기를 할 수 있습니다.
- **🗞️ 우리 반 팩트체크 자료:** 우리 반에 맞는 기사 자료를 직접 만들 수 있습니다.

## 안전과 개인정보

- 학생의 실명, 이메일, 사진, 음성은 받지 않습니다. 학생은 Firebase **익명 로그인**만 합니다(Google 계정 연결은 교사만 선택해서 씀).
- 학생은 입장 전에 “우리 집이나 친구 집 위치는 표시하지 않아요” 약속에 동의합니다.
- 보안 규칙(`firestore.rules`)이 지키는 것
  - 학급 코드를 아는 사람만 학급에 들어올 수 있습니다. 학급 목록은 그 학급을 만든 교사만 봅니다.
  - 친구에게 보이는 것은 지도에 남기는 활동(장소감, 개선, 기호, 문제 해결, 지역 알리기, 문화유산) 가운데 교사가 공개한 기록뿐입니다. 연표, 미션, 퀴즈, 분류하기, 시뮬레이션 기록은 학생 본인과 교사만 봅니다.
  - 학생은 자기 기록만 고치거나 지울 수 있고, 스스로 승인할 수 없습니다.
  - 학급 설정, 승인, 숨김은 학급을 만든 교사만 바꿀 수 있습니다.
  - 글자 수 제한(장소 30자, 이유 150자, 별명 10자 등)이 있고, 정해진 칸 외의 데이터는 저장할 수 없습니다.
- 사진은 위키미디어 공용에서 학생 브라우저로 바로 불러옵니다. 이때 학생 정보는 보내지 않습니다.
- 학교에서 쓰기 전에 학교의 개인정보 처리 절차를 확인해 주세요. 학부모님께 보낼 **[안내문 견본과 확인 목록](docs/parent-notice.md)**이 있습니다(앱의 📖 사용 안내에서도 복사할 수 있어요).

## 자주 묻는 질문

**학생 기록이 저장되지 않아요.**
Firebase 규칙 탭에 최신 `firestore.rules`를 붙여 넣고 **게시**했는지 확인해 주세요. 업데이트 뒤 새 활동에서 자주 생깁니다.

**사진이 안 보이고 그림 기호만 나와요.**
학교 인터넷이 위키미디어(`commons.wikimedia.org`, `upload.wikimedia.org`)를 막고 있을 수 있습니다. 활동은 그대로 할 수 있고, 학교 정보 담당 선생님께 허용을 부탁할 수 있습니다.

**체험 모드에서 학생 둘이 같은 화면을 봐요.**
체험 모드는 한 브라우저의 탭을 같은 사람으로 봅니다. 실제 수업은 학급 모드로 해 주세요.

**다른 기기에서 내 학급이 안 보여요.**
학급은 만든 브라우저에서 관리합니다. Google 계정을 연결해 두면 다른 기기에서도 볼 수 있습니다.

**학교 인터넷이 느리거나 자주 끊겨요.**
한 번 연 기기에는 앱 파일(화면, 활동, 세계·우리나라 지도 자료)이 저장돼, 인터넷이 느리거나 끊겨도 앱 화면이 바로 열립니다. 수업 전에 크롬북마다 한 번씩 열어 두세요. 학급 모드의 기록 저장, 학교 지도 그림, 사진은 인터넷이 있어야 합니다. 연결이 끊기면 화면 아래에 알림이 나오고, 학급 모드에서는 다시 연결될 때 기록이 저장됩니다(그때까지 창을 닫지 마세요). 새 버전을 올리면 기기가 30분 안에, 또는 다음에 열 때 새 파일을 받습니다.

**돈이 들 수 있나요?**
결제 수단을 등록하지 않은 Firebase 무료 요금제에서는 요금이 청구되지 않습니다. 한도를 넘으면 그날만 멈춥니다.

## 개발자용

```bash
npm install
npm run dev        # http://localhost:5173 (체험 모드)
npm run build      # dist/ 에 배포 파일 생성
```

Firebase 에뮬레이터로 학급 모드를 내 컴퓨터에서 시험하려면 다음 순서로 실행합니다(Java 필요).

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-scm
```

포트 설정(Firestore 8085, Auth 9099)은 `firebase.json`에 들어 있습니다. 에뮬레이터를 켠 상태에서 다른 터미널로 앱을 실행합니다.

```bash
VITE_FIREBASE_EMULATOR=1 npm run dev
```

에뮬레이터에서는 Google 팝업 대신 가짜 토큰으로 계정 연결을 시험할 수 있습니다. 브라우저 콘솔에서 아래를 실행한 뒤 “Google 계정 연결”을 누릅니다.

```js
window.__scmTestGoogleToken = JSON.stringify({ sub: 'test-1', email: 't@example.com', email_verified: true });
```
