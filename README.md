# 🗺️ 우리 동네 지도 탐구

초등 사회 3~6학년 수업에서 쓰는 웹앱입니다. 학교 주변 지도 활동을 중심으로, 연표·경제·선거·미디어 활동까지 담았습니다.
학생들이 크롬북으로 활동하면 선생님 화면에 실시간으로 모입니다.

| 단원 | 활동 | 성취기준 | 학생이 하는 일 |
|---|---|---|---|
| 3-1 (1) 우리가 사는 곳 | 나의 장소감 지도 | [4사01-01] | 기억에 남는 장소에 느낌(이모지)과 이유를 남기고, 친구의 장소감에 공감하기 |
| | 더 살기 좋은 우리 동네 | [4사01-02] | 불편하거나 위험한 곳에 문제와 개선 방법(신호등, 벤치 등)을 표시하기 |
| 3-1 (2) 일상에서 만나는 과거 | 나의 연표 만들기 | [4사02-01] | 태어난 해부터 기억에 남는 일을 연도와 함께 넣어 연표 만들기 (나와 선생님만 봄) |
| 4-1 (5) 지도로 만나는 우리 지역 | 방위와 거리 미션 | [4사05-01·02] | 방위표와 축척 막대로 “학교의 북쪽”, “학교에서 약 300m” 같은 장소를 찾기. 앱이 바로 확인하고, 틀리면 답 대신 힌트를 줌 |
| | 우리 반 지도 기호 만들기 | [4사05-01] | 병원·도서관 같은 장소를 나타낼 기호를 직접 정해 표시하기. 우리 반 범례가 자동으로 만들어짐 |
| 4-1 (7) 경제활동과 지역 간 교류 | 기회비용 장터 | [4사07-01] | 용돈 5,000원으로 물건을 고르고, 포기한 것 중 가장 아쉬운 것(기회비용)과 까닭 적기 |
| 4-2 (9) 지역문제 해결과 지역 알리기 | 우리 동네 문제 해결하기 | [4사09-01] | ① 문제 찾기 → ② 원인 생각하기 → ③ 두 가지 방법의 좋은 점·아쉬운 점 비교 → ④ 결론 내리기 |
| | 우리 지역 알리기 | [4사09-02] | 우리 지역의 자랑거리를 표시하고 한 줄 홍보 문구 만들기 |
| 6-1 (8) 민주주의와 시민 참여 | 선거 4원칙 지키기 | [6사08-01] | 원칙이 깨진 “행복섬” 선거 이야기 6개를 읽고 어떤 원칙인지 찾기. 틀리면 힌트 |
| | 팩트체크 스튜디오 | [6사08-03] | 같은 일을 다룬 기사·개인 방송·광고에서 문장마다 사실/의견을 표시하고, 출처를 따져 믿을 만한지 판단하기 |

- 설치 없이 웹 주소로 실행합니다. 크롬북을 기준으로 만들었고 태블릿에서도 동작합니다.
- 비용이 들지 않습니다. GitHub Pages, Firebase 무료 요금제, 브라우저 내장 음성을 씁니다.
- 학생 개인정보를 받지 않습니다. 학급 코드와 번호, 선택 별명만 씁니다.

## 1. 바로 써 보기 (체험 모드)

아무 설정 없이 배포 주소를 열면 **체험 모드**로 동작합니다.

- 기록은 그 브라우저에만 저장됩니다.
- 같은 크롬북에서 탭을 두 개 열고 한쪽은 “선생님”, 다른 쪽은 “학생”으로 들어가면, 실시간으로 연결되는 모습을 혼자 시연할 수 있습니다.
- 체험 모드에서는 한 브라우저의 탭들이 모두 같은 사람으로 취급됩니다. 그래서 학생 탭을 여러 개 열면 서로의 기록을 자기 것처럼 봅니다. 학생 구분은 학급 모드에서 정확히 동작합니다.
- 여러 학생의 크롬북을 연결하려면 아래 **3. 학급 모드 켜기**가 필요합니다.

배포 주소: `https://oswprogram10-tech.github.io/Social-class-module/`
(아래 2번을 처음 한 번 마친 뒤부터 열립니다.)

## 2. 배포하기 (GitHub Pages, 처음 한 번)

1. GitHub 저장소에서 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이후 `main` 브랜치가 바뀔 때마다 자동으로 배포됩니다. 진행 상황은 **Actions** 탭에서 볼 수 있습니다.

> 코드를 직접 고치지 않아도 됩니다. 설정값은 GitHub 웹에서 `src/config.ts` 파일을 열고 연필(✏️) 아이콘으로 수정한 뒤 **Commit changes**를 누르면 1~2분 뒤 반영됩니다.

## 3. 학급 모드 켜기 (Firebase, 무료)

여러 크롬북을 실시간으로 연결하려면 Firebase 프로젝트가 필요합니다. 약 10분 걸립니다.

1. <https://console.firebase.google.com> 에 Google 계정으로 들어가 **프로젝트 추가**를 누릅니다.
   - 이름 예: `social-class-module`
   - Google 애널리틱스는 **사용 안 함**으로 둡니다.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누르고, **로그인 방법**에서 **익명**을 사용 설정합니다.
3. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작합니다.
4. Firestore의 **규칙** 탭을 열고, 기존 내용을 모두 지운 뒤 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 **게시**합니다.
5. **프로젝트 설정(⚙️) → 일반 → 내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록합니다(호스팅 체크는 하지 않음).
6. 화면에 나오는 `firebaseConfig` 값을 [`src/config.ts`](src/config.ts)의 `firebaseConfig`에 옮겨 적고 커밋합니다.

배포가 끝나면 첫 화면의 노란 “체험 모드” 안내가 사라집니다. 이것이 학급 모드로 바뀌었다는 표시입니다.

**(선택) 다른 기기에서도 학급 관리하기:** 교사가 Google 계정을 연결해 두면, 학급을 만든 크롬북이 아닌 다른 기기에서도 관리할 수 있습니다.

1. **Authentication → 로그인 방법**에서 **Google**을 사용 설정합니다.
2. **Authentication → 설정 → 승인된 도메인**에 `oswprogram10-tech.github.io`를 추가합니다.
3. 학급을 만든 크롬북의 교사 화면 아래쪽에서 **Google 계정 연결**을 누릅니다.
4. 다른 기기에서는 첫 화면의 **🔑 다른 기기에서 내 학급 관리하기**에서 같은 Google 계정으로 로그인합니다.

학생은 Google 계정을 쓰지 않습니다.

**비용:** Spark(무료) 요금제는 결제 수단을 등록하지 않아 요금이 청구되지 않습니다. 하루 한도(읽기 5만 건 등)를 넘으면 그날만 멈추며, 한 학급이 수업에서 쓰는 양은 한도보다 훨씬 적습니다. 결제 수단을 등록(Blaze 요금제로 전환)하지 마세요.

> `firebaseConfig` 값은 공개되어도 괜찮은 값입니다. 데이터는 `firestore.rules` 보안 규칙이 지킵니다.

## 4. (선택) 브이월드 지도로 바꾸기

기본 지도는 OpenStreetMap입니다. 국토교통부 **브이월드** 키를 넣으면 국내 배경지도와 **영상지도(항공사진)**로 바꿔 볼 수 있습니다.

1. <https://www.vworld.kr> 에 가입한 뒤 **오픈API → 인증키 발급**을 진행합니다.
2. 서비스 URL에 `https://oswprogram10-tech.github.io`를 입력합니다.
3. 발급된 키를 [`src/config.ts`](src/config.ts)의 `vworldKey`에 넣고 커밋합니다.

## 5. 수업에서 쓰기

**준비 (교사)**
1. 첫 화면에서 **선생님: 학급 만들기**를 누릅니다.
2. 학교를 검색하거나 지도에서 눌러 위치를 정하고, 탐색 범위(500m~3km)를 고릅니다.
3. 교사 화면 위쪽의 **학급 코드**를 TV에 띄우거나, **입장 주소 복사**로 링크를 클래스룸에 올립니다.

**1차시: 나의 장소감 지도 [4사01-01]**
- 학생은 코드, 번호, 별명을 입력하고 “우리의 약속”(집 위치 표시 금지, 친구 존중)에 동의한 뒤 들어갑니다.
- 기억에 남는 장소를 누르고, 느낌을 고르고, 이유를 적습니다. 🔊 버튼으로 안내를 들을 수 있습니다.
- 친구 핀을 눌러 💛 공감할 수 있습니다.
- 교사는 **🖥️ 발표 화면**으로 바꾸면 지도, 느낌 통계, 토의 질문을 크게 보여 줄 수 있습니다.
  예: “같은 놀이터인데 왜 누구는 신나고 누구는 무서울까?”

**2차시: 더 살기 좋은 우리 동네 [4사01-02]**
- 교사 화면에서 **더 살기 좋은 우리 동네** 탭을 누르면 모든 학생 화면이 바로 바뀝니다.
- 학생은 불편하거나 위험한 곳에 문제(⚠️ 위험해요 등)와 개선 방법(🚦 신호등 등)을 고르고 이유를 적습니다.

**4학년 1학기: 방위와 거리 미션 [4사05-01·02]**
- 교사 화면에서 **방위와 거리 미션** 탭을 누릅니다. 지도 왼쪽 위에 방위표가, 왼쪽 아래에 축척 막대가 있습니다.
- 미션은 6개입니다: 북·동·남·서쪽 탐험, 300m 찾기, 600m 찾기.
- 학생이 장소를 표시하고 이름을 적어 “확인하기”를 누르면 앱이 학교 위치를 기준으로 바로 확인합니다.
  - 틀리면 정답 대신 힌트를 줍니다. 예: “표시한 곳은 학교의 북쪽이에요. 방위표를 보고 동쪽이 지도의 어느 방향인지 다시 찾아볼까요?”
- 교사 화면에는 **학생 × 미션 진행표**(✅ 성공, 🔁 다시 도전, 숫자는 시도 횟수)가 나옵니다. 미션 답은 친구에게 보이지 않습니다.

**3학년 1학기: 나의 연표 만들기 [4사02-01]**
- 지도 대신 연표 화면이 나옵니다. 학생은 연도, 있었던 일, 그림을 넣고, 연표는 자동으로 옛날부터 지금 순서로 정렬됩니다.
- 가족 이야기가 들어갈 수 있어 **연표는 학생 본인과 선생님만** 볼 수 있습니다. 선생님 화면에는 학생별 연표가 차례로 나옵니다.

**4학년 1학기: 우리 반 지도 기호 만들기 [4사05-01]**
- 학생은 장소 종류(병원, 도서관 등)를 고르고, 그 장소를 나타낼 기호를 직접 정한 뒤 까닭을 적습니다.
- 지도 오른쪽 아래에 **우리 반 범례**가 자동으로 만들어집니다. 같은 장소를 친구들이 서로 다른 기호로 나타내면 ⚠️ 표시가 생깁니다.
  - 이를 계기로 “지도를 보는 모든 사람이 이해하려면 기호를 어떻게 정해야 할까?”를 토의할 수 있습니다.

**4학년 2학기: 우리 동네 문제 해결하기 [4사09-01]**
- 학생은 4단계로 진행하고, 단계마다 저장됩니다. 교사는 누가 어느 단계에 있는지 실시간으로 볼 수 있어, 막힌 학생을 바로 도울 수 있습니다.
- 완성한 해결 방안만 친구에게 보이고, 친구의 해결 방안에 💛 공감할 수 있습니다.
- 발표 화면에서 해결 방안을 하나씩 눌러 보여 주며 토의할 수 있습니다.

**4학년 2학기: 우리 지역 알리기 [4사09-02]**
- 학생은 자랑거리(자연환경, 문화유산, 축제, 특산물 등)를 지도에 표시하고, 다른 지역 사람이 가 보고 싶어지는 한 줄 홍보 문구를 만듭니다.
- 친구들의 홍보 카드를 눌러 보고 💛 공감할 수 있습니다. 발표 화면에서 카드를 하나씩 보여 주며 이야기 나누기 좋습니다.

**4학년 1학기: 기회비용 장터 [4사07-01]**
- 학생은 용돈 5,000원으로 물건 8가지 중 사고 싶은 것을 고릅니다. 돈이 모자라면 앱이 알려 줍니다.
- 다 고른 뒤에는 고르지 못한 것 중 가장 아쉬운 것, 곧 **기회비용**을 고르고 까닭을 적습니다.
- 선생님 화면에는 학생별로 산 것, 쓴 돈, 기회비용이 표로 나옵니다.

**6학년 1학기: 선거 4원칙 지키기 [6사08-01]**
- 지어낸 “행복섬” 선거 이야기 6개를 읽습니다. 각 이야기에는 원칙이 깨져서 생긴 일이 함께 나옵니다.
- 학생은 지켜지지 않은 원칙(보통·평등·직접·비밀)을 고릅니다. 틀리면 정답 대신 생각을 돕는 질문이 나옵니다.
- 모두 해결하면 가장 중요하다고 생각하는 원칙과 까닭을 적습니다.
- 선생님 화면에는 학생 × 이야기 결과표와 시도 횟수가 나옵니다.

**6학년 1학기: 팩트체크 스튜디오 [6사08-03]**
- “놀이터 자리에 주차장을 짓는 계획”을 다룬 신문 기사, 개인 방송, 광고 자료가 들어 있습니다. 모두 지어낸 자료입니다.
- 학생은 문장을 눌러 사실/의견을 표시하고 “확인하기”를 누릅니다. 틀린 문장은 빨간 테두리로만 알려 주고 정답은 보여 주지 않습니다.
- 다음 단계에서는 출처 체크리스트 5문항에 답하고, 자료를 얼마나 믿을 수 있는지(👍/🤔/⚠️)와 까닭을 적습니다.
- **우리 반 자료 만들기:** 선생님 화면의 “🗞️ 우리 반 자료”에서 본문을 붙여 넣으면 문장으로 나뉘고, 문장마다 정답을 정해 저장할 수 있습니다(최대 10개).

> 연표, 미션, 기회비용 장터, 선거, 팩트체크 기록은 학생 본인과 선생님만 볼 수 있습니다. 보안 규칙에서도 막혀 있습니다. 발표 화면에서는 학생별 표 대신 반 전체 요약만 보입니다.

**관리 기능**
- **✏️ 생각 도우미 질문 고치기:** 활동마다 학생에게 보여 줄 질문을 우리 반에 맞게 바꿀 수 있습니다(최대 5개). 바꾼 질문은 발표 화면에도 나옵니다.
- **선생님이 승인한 장소만 친구에게 공개:** 저학년이나 첫 수업에서 켜 두면 부적절한 글이 친구에게 보이지 않습니다.
- **학생들이 친구 장소 보기:** 끄면 각자 자기 장소만 봅니다.
- 핀마다 승인, 숨기기, 지우기를 할 수 있습니다.
- **📥 엑셀로 저장:** 모든 활동의 기록(장소감, 연표, 미션, 기호, 기회비용, 문제 해결 4단계, 홍보 문구, 선거, 팩트체크)을 CSV로 내려받아 과정 중심 평가 기록에 활용합니다.
- **🧹 모두 지우기:** 학기 말에 학급 데이터를 정리합니다.

> 학급은 학급을 만든 브라우저에서 관리합니다. 다른 기기에서도 관리하려면 위의 “Google 계정 연결”을 해 두세요.

## 6. 안전과 개인정보 설계

- 학생의 실명, 이메일, 사진, 음성은 받지 않습니다. 학생은 Firebase **익명 로그인**만 합니다(Google 계정 연결은 교사만 선택적으로 씀).
- 학생은 입장 전에 “우리 집이나 친구 집 위치는 표시하지 않아요” 약속에 동의해야 합니다.
- 보안 규칙(`firestore.rules`)이 지키는 것
  - 학급 코드를 아는 사람만 학급에 들어올 수 있습니다. 학급 목록은 교사 본인 것만 볼 수 있습니다.
  - 학생은 자기 기록과, 교사가 공개한 친구 기록만 읽을 수 있습니다. 친구 기록은 장소감, 개선, 기호, 문제 해결, 지역 알리기 활동만 해당합니다.
  - 학생은 자기 핀만 고치거나 지울 수 있고, 스스로 승인할 수 없습니다.
  - 학급 설정, 승인, 숨김은 학급을 만든 교사만 바꿀 수 있습니다.
  - 글자 수 제한: 장소 30자, 이유 150자, 별명 10자 등. 정해진 칸 외의 데이터는 저장할 수 없습니다.
- 학교에서 사용하기 전에 학교의 개인정보 처리 절차(학부모 안내 등)를 확인하세요.

## 개발자용

```bash
npm install
npm run dev        # http://localhost:5173 (체험 모드)
npm run build      # dist/ 에 배포 파일 생성
```

Firebase 에뮬레이터로 학급 모드를 내 컴퓨터에서 시험하려면 다음 순서로 실행합니다(Java 필요).

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-scm
```

포트 설정(Firestore 8085, Auth 9099)은 `firebase.json`에 들어 있습니다. 에뮬레이터를 켠 상태에서 다른 터미널로 앱을 실행합니다.

```bash
VITE_FIREBASE_EMULATOR=1 npm run dev
```

에뮬레이터에서는 Google 팝업 대신 가짜 토큰으로 계정 연결을 시험할 수 있습니다. 브라우저 콘솔에서 아래를 실행한 뒤 “Google 계정 연결”을 누릅니다.

```js
window.__scmTestGoogleToken = JSON.stringify({ sub: 'test-1', email: 't@example.com', email_verified: true });
```
