# 🗺️ 우리 동네 장소감 지도

초등 사회 3학년 1학기 **(1) 우리가 사는 곳** 수업에서 쓰는 웹앱입니다.
학생들이 크롬북으로 학교 주변 지도에 장소감과 개선 아이디어를 남기면, 선생님 화면에 실시간으로 모입니다.

| 활동 | 성취기준 | 학생이 하는 일 |
|---|---|---|
| 나의 장소감 지도 | [4사01-01] | 기억에 남는 장소에 느낌(이모지)과 이유를 남기고, 친구의 장소감에 공감하기 |
| 더 살기 좋은 우리 동네 | [4사01-02] | 불편하거나 위험한 곳에 문제와 개선 방법(신호등, 벤치 등)을 표시하기 |

- 설치 없이 웹 주소로 실행합니다. 크롬북을 기준으로 만들었고 태블릿에서도 동작합니다.
- 비용이 들지 않습니다. GitHub Pages, Firebase 무료 요금제, 브라우저 내장 음성을 씁니다.
- 학생 개인정보를 받지 않습니다. 학급 코드와 번호, 선택 별명만 씁니다.

---

## 1. 바로 써 보기 (체험 모드)

아무 설정 없이 배포 주소를 열면 **체험 모드**로 동작합니다.

- 기록은 그 브라우저에만 저장됩니다.
- 같은 크롬북에서 탭을 두 개 열고 한쪽은 “선생님”, 다른 쪽은 “학생”으로 들어가면, 실시간으로 연결되는 모습을 혼자 시연할 수 있습니다.
- 여러 학생의 크롬북을 연결하려면 아래 **3. 학급 모드 켜기**가 필요합니다.

배포 주소: `https://oswprogram10-tech.github.io/Social-class-module/`
(아래 2번을 처음 한 번 마친 뒤부터 열립니다.)

## 2. 배포하기 (GitHub Pages, 처음 한 번)

1. GitHub 저장소에서 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이후 `main` 브랜치가 바뀔 때마다 자동으로 배포됩니다. 진행 상황은 **Actions** 탭에서 볼 수 있습니다.

> 코드를 직접 고치지 않아도 됩니다. 설정값은 GitHub 웹에서 `src/config.ts` 파일을 열고 연필(✏️) 아이콘으로 수정한 뒤 **Commit changes**를 누르면 1~2분 뒤 반영됩니다.

## 3. 학급 모드 켜기 (Firebase, 무료)

여러 크롬북을 실시간으로 연결하려면 Firebase 프로젝트가 필요합니다. 약 10분 걸립니다.

1. <https://console.firebase.google.com> 에 Google 계정으로 들어가 **프로젝트 추가**를 누릅니다.
   - 이름 예: `social-class-module`
   - Google 애널리틱스는 **사용 안 함**으로 둡니다.
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 누르고, **로그인 방법**에서 **익명**을 사용 설정합니다.
3. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작합니다.
4. Firestore의 **규칙** 탭을 열고, 기존 내용을 모두 지운 뒤 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣고 **게시**합니다.
5. **프로젝트 설정(⚙️) → 일반 → 내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록합니다(호스팅 체크는 하지 않음).
6. 화면에 나오는 `firebaseConfig` 값을 [`src/config.ts`](src/config.ts)의 `firebaseConfig`에 옮겨 적고 커밋합니다.

배포가 끝나면 첫 화면의 노란 “체험 모드” 안내가 사라집니다. 이것이 학급 모드로 바뀌었다는 표시입니다.

**비용:** Spark(무료) 요금제는 결제 수단을 등록하지 않아 요금이 청구되지 않습니다. 하루 한도(읽기 5만 건 등)를 넘으면 그날만 멈추며, 한 학급이 수업에서 쓰는 양은 한도보다 훨씬 적습니다. 결제 수단을 등록(Blaze 요금제로 전환)하지 마세요.

> `firebaseConfig` 값은 공개되어도 괜찮은 값입니다. 데이터는 `firestore.rules` 보안 규칙이 지킵니다.

## 4. (선택) 브이월드 지도로 바꾸기

기본 지도는 OpenStreetMap입니다. 국토교통부 **브이월드** 키를 넣으면 국내 배경지도와 **영상지도(항공사진)**로 바꿔 볼 수 있습니다.

1. <https://www.vworld.kr> 에 가입한 뒤 **오픈API → 인증키 발급**을 진행합니다.
2. 서비스 URL에 `https://oswprogram10-tech.github.io`를 입력합니다.
3. 발급된 키를 [`src/config.ts`](src/config.ts)의 `vworldKey`에 넣고 커밋합니다.

## 5. 수업에서 쓰기

**준비 (교사)**
1. 첫 화면에서 **선생님: 학급 만들기**를 누릅니다.
2. 학교를 검색하거나 지도에서 눌러 위치를 정하고, 탐색 범위(500m~3km)를 고릅니다.
3. 교사 화면 위쪽의 **학급 코드**를 TV에 띄우거나, **입장 주소 복사**로 링크를 클래스룸에 올립니다.

**1차시: 나의 장소감 지도 [4사01-01]**
- 학생은 코드, 번호, 별명을 입력하고 “우리의 약속”(집 위치 표시 금지, 친구 존중)에 동의한 뒤 들어갑니다.
- 기억에 남는 장소를 누르고, 느낌을 고르고, 이유를 적습니다. 🔊 버튼으로 안내를 들을 수 있습니다.
- 친구 핀을 눌러 💛 공감할 수 있습니다.
- 교사는 **🖥️ 발표 화면**으로 바꾸면 지도, 느낌 통계, 토의 질문을 크게 보여 줄 수 있습니다.
  예: “같은 놀이터인데 왜 누구는 신나고 누구는 무서울까?”

**2차시: 더 살기 좋은 우리 동네 [4사01-02]**
- 교사 화면에서 **더 살기 좋은 우리 동네** 탭을 누르면 모든 학생 화면이 바로 바뀝니다.
- 학생은 불편하거나 위험한 곳에 문제(⚠️ 위험해요 등)와 개선 방법(🚦 신호등 등)을 고르고 이유를 적습니다.

**관리 기능**
- **선생님이 승인한 장소만 친구에게 공개:** 저학년이나 첫 수업에서 켜 두면 부적절한 글이 친구에게 보이지 않습니다.
- **학생들이 친구 장소 보기:** 끄면 각자 자기 장소만 봅니다.
- 핀마다 승인, 숨기기, 지우기를 할 수 있습니다.
- **📥 엑셀로 저장:** 번호, 장소, 느낌, 이유를 CSV로 내려받아 평가 기록에 활용합니다.
- **🧹 모두 지우기:** 학기 말에 학급 데이터를 정리합니다.

> 학급을 관리할 수 있는 브라우저는 학급을 만든 브라우저 하나뿐입니다. 같은 크롬북, 같은 계정으로 열어 주세요.

## 6. 안전과 개인정보 설계

- 실명, 이메일, 사진, 음성은 받지 않습니다. 학생은 Firebase **익명 로그인**만 합니다.
- 학생은 입장 전에 “우리 집이나 친구 집 위치는 표시하지 않아요” 약속에 동의해야 합니다.
- 보안 규칙(`firestore.rules`)이 지키는 것
  - 학급 목록 조회 금지. 학급 코드를 아는 사람만 들어올 수 있습니다.
  - 학생은 자기 핀과, 교사가 공개한 친구 핀만 읽을 수 있습니다.
  - 학생은 자기 핀만 고치거나 지울 수 있고, 스스로 승인할 수 없습니다.
  - 학급 설정, 승인, 숨김은 학급을 만든 교사만 바꿀 수 있습니다.
  - 글자 수 제한: 장소 30자, 이유 150자, 별명 10자.
- 학교에서 사용하기 전에 학교의 개인정보 처리 절차(학부모 안내 등)를 확인하세요.

## 개발자용

```bash
npm install
npm run dev        # http://localhost:5173 (체험 모드)
npm run build      # dist/ 에 배포 파일 생성
```

Firebase 에뮬레이터로 학급 모드를 내 컴퓨터에서 시험하려면 다음 순서로 실행합니다(Java 필요).

```bash
npx firebase-tools emulators:start --only auth,firestore --project demo-scm
```

포트 설정(Firestore 8085, Auth 9099)은 `firebase.json`에 들어 있습니다. 에뮬레이터를 켠 상태에서 다른 터미널로 앱을 실행합니다.

```bash
VITE_FIREBASE_EMULATOR=1 npm run dev
```

**구조**

```
src/
  activities.ts          활동 정의(성취기준, 안내, 생각 도우미 질문, 선택지)
  config.ts              Firebase·브이월드 설정
  data/
    types.ts             데이터 형식과 저장소 인터페이스
    localStore.ts        체험 모드(브라우저 저장, 탭 간 실시간 동기화)
    firebaseStore.ts     학급 모드(Firestore 실시간)
  components/            지도(Leaflet), 핀 입력·카드, 읽어주기(TTS)
  pages/                 첫 화면, 학급 만들기, 교사 화면, 학생 입장, 학생 지도
firestore.rules          Firestore 보안 규칙
firebase.json            에뮬레이터 설정
docs/roadmap.md          앞으로의 개발 계획
```

새 활동을 추가하려면 `src/activities.ts`에 활동을 정의하는 것부터 시작합니다. 앞으로의 계획은 [docs/roadmap.md](docs/roadmap.md)에 있습니다.
